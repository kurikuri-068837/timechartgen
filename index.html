設計ワークスペース

信号を自動収集し、クロック境界と遅延を見える化します。

1. RTL / 式を貼り付け

幅の提案は「最大時間 ÷ クロック周期」を保持するカウンタとして計算します。丸め、サチュレーション、符号付き演算は最終レビュー対象です。

2. 信号一覧・依存関係

信号種別 / 幅ドメイン更新モデルクロック判定参照先

3. 編集可能タイムチャート

各サイクルは pos / neg の順に二分割しています。クロックは pos=1 から開始し、neg=0 へ遷移します。各セルはプルダウンで編集します。多ビット信号は行ごとに bool / decimal / hex の表示基数を選べ、任意値も指定できます。

Cycle 0
クロック波形1 / 数値X / Z—（未指定）

4. 分周クロック設定

基準・独立・分周クロックごとに開始エッジを選べます。Offsetは選択した開始エッジを何サイクル後に出すか、High / Lowは分周クロックの保持周期です。

5. 波形ビュー・出力

セルの値と同じ状態モデルから再描画します。多ビット値は、値が変わるまで1本の連結したバスとして表示します。
